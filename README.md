CLI script to generate passwords and passphrases. Uses the list of English words library for passphrases: https://github.com/dwyl/english-words

Current features:

- Generate passwords and passphrases (Character limit of 99).
- Select password complexity (Types of characters in passwords, number of words in passphrases, etc).
- Provide statistics of generated password, such as password entropy and days to break (Based on an estimate of 10.000.000 hashes/second).

Features I might add later on:

- Command-line switches to generate passwords without interacting with the CLI.
- Better format of the statistics display.
- Allow exporting the password to a file.
